# gazeprotocol.github.io

The official Gaze links page, served at https://gazeprotocol.github.io (and `links.gazeprotocol.com` once DNS is set).

One static `index.html`, styled from the Gaze brand kit, with self-hosted Geist fonts. Edit links in `index.html` and open a pull request.
